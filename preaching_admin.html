Preacher Settings
Mainstay preachers do NOT rotate through Wednesday slots and skip the last Sunday of each month (which goes to rotation). The single mainstay (or first-flagged if multiple) auto-fills Sundays 1 to (last - 1).
A "recurring" preacher claims one slot in every cycle (e.g., every 3rd Wed). The cycle re-anchors from their most recent preaching date, so swaps don't break the pattern.
Leave blank if available. Auto-fill will skip this preacher up to and including this date, then auto-reactivate them. Use for cataract op, travel, sabbatical, etc.
